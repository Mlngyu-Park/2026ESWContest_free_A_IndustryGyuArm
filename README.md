# ARM STUDIO

![공장 화면](docs/factory.png)

로봇팔을 블록 코딩으로 제어하는 프로그램. 브라우저에서 블록을 이어 동작을 만들고,
3D 시뮬레이션으로 확인한 뒤 실물로 실행한다. 마이크에 대고 말하면 블록이 만들어지는
음성 입력도 붙어 있다.

## 기능

### 공장 꾸미기

설비 STL을 드래그해서 배치한다. 끌고 오면 실물 모양이 커서를 따라오고,
다리(핀) 2개를 목심에 클릭해서 자리와 회전을 정한다.
물체는 항상 도킹 스테이션 위에 올라간다 (중심축 일치).

개체마다 이름과 색을 줄 수 있고, 도킹은 배치 순서대로 빨강#8, 주황#9, 노랑#12를
받는다. 지우고 다시 깔아도 같은 라벨이 나오게 해서 시연 재현이 되게 했다.

목심 도달표는 로봇 상대좌표로 저장하므로 로봇이나 설비를 옮겨도 재계산이 없다.

### 블록 파이프라인

스크래치처럼 팔레트에서 끌어다 놓는다. 블록 종류는
이동 / 잡기(열기-하강-닫기-상승) / 놓기(하강-열기-상승-닫기) / 그리퍼 / 하강 / 상승.

잡기와 놓기는 좌표를 갖지 않는다. 어디서 할지는 바로 앞의 이동 블록이 정한다.
좌표를 두 군데서 계산하면 반드시 어긋나기 때문에 (실측 23mm) 이렇게 못박았다.

이동 블록은 실행하는 순간 대상 위치를 다시 계산한다. 파이프라인 중간에 물체가
옮겨져도 현재 위치로 간다. Ctrl+Z 되고, 3D 미리보기는 잡기·놓기까지 전부 재생한다.

### 말로 만들기

마이크 녹음을 DGX Spark의 Whisper로 보내 한국어 텍스트를 받고 (말하는 동안
자막이 실시간으로 보인다), Gemma 4 E4B가 텍스트를 블록 목록으로 바꾼다.

"빨간 도킹에 있는 초록 펜을 노란 데 놓고, 다시 주황으로 옮겨" 같은
2단계 이송도 블록 7개로 풀린다. 실측 2~4초.

LLM은 블록만 고른다. 관절값 같은 건 절대 만들지 않는다. LLM이 낸 답도
그대로 안 믿고 후처리에서 검증한다: id를 정규화하고, 잡기 앞에 이동이
없으면 넣고, 목록에 없는 대상이 나오면 블록을 버리고 되묻는다.

Spark 연결이 없으면 규칙 파서로 알아서 넘어간다. 인터넷 없이도 기본 동작은 된다.

### 실물 실행

레퍼런스 하드웨어는 SO-ARM101 (Feetech STS3215, 6축). 시뮬과 실물이 같은
파이프라인을 쓰고, 3D에는 이론 자세를, 실물에만 보정값을 더해 보낸다.

진동 문제를 잡느라 모션 방식을 여러 번 갈아엎었는데, 결론은 단순한 쪽이 이겼다:
이동 중에는 모터를 읽지 않고 웨이포인트를 시간 간격으로 밀어 넣기만 한다.
축마다 이동량이 다르면 같이 도착하도록 속도만 맞춘다.

그리퍼는 다 닫힐 때까지 기다린다 (실측 3.2초. 안 기다리면 덜 닫힌 채 팔이
올라가서 물체를 놓친다). 닫는 중에 위치가 멈추면 잡은 것으로 보고 살짝만
조인다. 끝까지 조이면 과부하 보호가 걸리기 때문이다.

### 물컵 규칙

그리퍼 위에 물컵을 올려놓고 한 방울도 안 쏟는다는 제약을 시스템 전체에 걸었다.

```
j1        Z회전       기울기와 무관
j2 j3 j4  같은 X축    셋의 합이 기울기를 정한다 -> 한 묶음으로 이동
j5        Y축         돌리면 무조건 기울어진다 -> 항상 잠금
```

미세조정에서 j3에 +5도를 주면 j4가 -5도를 받아서 합을 지킨다.
이동 모드 5종에 전부 수평유지가 걸려 있다.

## 정밀도

공장 기본 게인(Kp32/Kd32/Ki0)은 정지 오차가 1.58도였다.
Kp64/Kd64/Ki4로 튜닝해서 0.35도, 진동 없음.
도달 허용치는 6 raw, 약 0.53도, 엔드이펙터 기준 3mm.

## 실행

```bash
~/2026_project/Industry_gyu_arm/start_pro.sh
# 브라우저에서 http://localhost:7900 (3D 뷰어는 7870)
```

start_pro.sh가 이전 서버 정리, Spark 연결(실패해도 됨), 앱 실행까지 한다.
로그는 /tmp/arm_studio.log.

WSL에서 실물을 쓰려면 Windows PowerShell에서 usbipd attach 먼저.
USB는 꽂으면 자동 인식된다.

| urdf/ | 로봇 3종: SO-ARM(STS3215), Dynamixel, UR15 |
