# 월드 레이첼 — Spot 물리 걷기 AI

Spot 의 다리 12개를 **물리 엔진(Rapier, 책꽂이 앱과 같은 것)** 으로 움직이고, 학습한 두뇌가 1초에 60번 관절 목표각을 정해 균형을 잡는다.
지금 책꽂이 앱의 Spot 은 발 자리를 계산해 그대로 놓는다(물리 없음). 월드 레이첼을 켜면 몸이 실제로 무게·관성·마찰을 받는다.

- 학습: 스파크(GB10)에서 CPU 10개 + GPU, 시행착오 강화학습(PPO). 1초에 약 2만 걸음.
- 앱에 넣기: `phys_walker.mjs` 가 계산 걷기(`spotkin.js` 의 Walker)와 같은 꼴(cmd · target · pose · vel · walking)이라 `spotb.js` 에 그대로 끼운다.
- 팔·잡기는 지금처럼 계산. 팔 무게(5.5kg)와 든 책 무게만 '팔 무게 점' 으로 물리에 넣는다 → 팔을 뻗으면 두뇌가 무게중심 이동을 버틴다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `spot_env.mjs` | 연습장: 물리 Spot(몸통 + 다리 4×3 = 물체 13개, 관절 12개), 관찰·점수·넘어짐. 브라우저·Node 같은 코드 |
| `worker.mjs` | 연습장 N개를 돌리는 일꾼 (학습기와 표준 입출력으로 숫자를 주고받음) |
| `train.py` | 학습기 (PPO, torch). 두뇌를 `policy_XXXXX.json` 으로 내보냄 |
| `policy.mjs` | 두뇌 실행 (JSON → 관찰 53개 넣으면 관절 12개). 바깥 라이브러리 없음 |
| `eval.mjs` | 시험: 정해진 명령 순서(서기·앞·옆·뒤·돌기, v2 는 + 숙이기·팔 뻗기)를 따라가게 하고 오차를 숫자로 |
| `view.html` | 3D 로 보며 키보드로 몰기 (W/S 앞뒤 · A/D 돌기 · Q/E 옆 · P 밀기 · R 처음부터, v2 는 몸 자세·팔 버튼) |
| `phys_walker.mjs` | 책꽂이 앱에 끼우는 물리 걷기 |
| `policies/` | 학습된 두뇌. `v2.json` = 앱이 쓰는 것, `latest.json` = view.html 기본 |

## 판 (v2 부터는 관찰 53 으로 같아서 앞 판에서 이어 배운다)

| 판 | 바꾼 것 | 왜 |
|---|---|---|
| v1 | 앞·옆·돌기 속도만 (관찰 51) | 걷기부터 |
| v2 | + 몸 높이(0.34~0.56m)·숙임(-0.1~0.4rad), 팔 무게 점(5.5~8kg)이 팔 무게중심 범위를 돌아다님, 느린 맞춤 걸음 | 책꽂이 앱이 숙이고 팔을 뻗는다 |
| v3 | 따라가기 점수를 엄격하게 (σ 0.25→0.1, 가중 1.5→2.0 · 0.8→1.2), 걸을 땐 팔 무게를 접음·책 든 자세 근처로 | v2 는 0.4m/s 를 0.2 로 걸어도 15% 만 잃어 '느리게 걷기' 가 이득이었다 |
| v4 | + 1초 동안 쌓인 따라가기 오차 점수, 제자리 조금 돌기(0.1~0.35rad/s)·조금 옮기기 | 0.1rad/s 같은 작은 명령을 '서 있기' 로 무시해 도착을 못 했다 |
| v5 | + 숙인 채 천천히 걷기 (0.36~0.46m, ≤0.2m/s) | 책을 칸에서 빼며 숙인 채 25cm 뒤로 물러나는 단계에서 멈췄다 |

v5 1400번째 시험: 앞 0.4 오차 0.06m/s · 돌기 0.6 오차 0.10 · 옆 0.25 오차 0.10 · 숙인 채 뒤로 0.15 오차 0.12 · 제자리 조금 돌기 0.15 오차 0.06, 몸 높이 오차 0.2~1.9cm · 숙임 오차 ≤2.2°.

## 앱에 끼울 때 정한 것 (`phys_walker.mjs`, 11-02 — 책꽂이 공정을 끝까지 돌리며 하나씩 찾음)

- **작은 명령 올리기**: 0 이 아닌데 0.1m/s · 0.25rad/s 보다 작으면 그만큼으로 (두뇌는 더 작은 명령을 '서 있기' 로 받는다).
- **도착 문턱**: 들어갈 땐 2cm·0.04rad (계산 걷기와 같음), 그 목표에 한 번 들어온 뒤엔 3.5cm·0.07rad. 새 목표면 다시 처음 값 (`aim`).
  물리 몸은 서 있어도 1~2mm 흔들려, 문턱에서 '도착/아님' 이 깜빡이면 명령이 0↔움직임으로 바뀌어 두뇌가 발을 못 뗐다.
- **멈춤 판정**: 몸 속도를 0.25초로 고르게 해서 (흔들림은 0).
- **몸 자세가 된 뒤 자리 다시 맞추기** (`settleAt`, spotb '몸 높이' 단계): 숙이면 몸이 앞으로 10cm 밀렸다 → 2.5cm·0.05rad 안으로. 8초 넘으면 그대로.
- **자리 지키기**: 앱 명령이 0 인 동안(팔로 일할 때) 멈춘 자리에서 1.5cm·0.03rad 넘게 밀리면 되돌아간다 (팔 무게가 움직이면 3초에 4cm 밀렸다).
- **서 있을 땐 앱이 '계획한 몸' 을 본다**: 멈춘 자리 + 명령한 높이·숙임(자세가 된 뒤). 팔·손 계산이 계획대로 가고, 실제 몸은 자리 지키기로 1.5cm 안.
  진짜 Spot 이 몸이 흔들려도 손을 세상에 고정하는 것(몸 전체 제어)과 같은 가정. 실제 몸으로 팔을 계산하면 손가락이 책을 6mm 놓쳤다.
  손은 원래부터 물리가 아니라 계산(책 물리에는 손 모양이 계산 자리로 들어간다)이라 이 가정과 맞는다.
- 같이 고친 앱 쪽 (`duo_studio/web`): `spotb.js` hdrive 의 문턱을 걷기 쪽이 정하게(`wk.tol`) · 새 목표 알림(`wk.aim`) · '몸 높이' 단계에 자리 다시 맞추기,
  `bookworld.js` 넣기 앞 자세를 18cm 하나에서 18·13·8·23cm 후보로 + 앞 자세가 안 풀리면 목표 자세 답에서 다시 풀기 (팔 끝자락에서 시작 자세에 따라 풀이가 갈렸다 — 계산 걷기도 좋아짐).

책꽂이 앱의 몸 자세: 보통 0.52m/0° · 낮게 0.40/0.12 · 가운데 0.44/0.15 · 깊게 0.36m/0.35rad(20°) — v2 가 이 범위를 배운다.

## 물리 설정에서 실측으로 정한 것 (11-02)

- **관절 세기 250 · 감쇠 6** (힘 한도 엉덩이 45 · 무릎 115 N·m, Spot 실물 값). 80 이면 AI 없이 섰을 때 몸통이 52→36cm 로 주저앉는다.
- **관절 힘은 '한 물리 걸음 동안 가하는 힘'(addTorque)** 으로. 순간 충격(applyTorqueImpulse)으로 주면 서 있기만 해도 10초에 62cm 미끄러진다 → 힘으로 바꾸니 4cm.
- **아랫다리 1.0kg + 발 0.5kg** (실물 0.35kg). Rapier 는 닿는 물체가 가벼우면 바닥에 파묻힌다 (발 공 반지름 3.6cm 인데 1.5~3cm 파묻힘 → 무겁게 하니 4.5mm). 몸통을 그만큼 가볍게 해 총 40kg.
- **충격식 이음** (다관절 이음은 벌어짐 0 이지만 1.5배 느림). 다리를 막 흔들어도 이음 벌어짐 최대 3.6mm.
- **부딪힘 모양은 상자** (점 껍질은 3.4배 느림). 땅에 닿는 건 발 공·정강이 막대뿐.
- 물리 1초 240번(화면 1장 = 4번) · 두뇌 1초 60번. 계산 (제 PC 코어 1개, 책꽂이 앱 안에서): 화면 한 장에 걷기 0.84ms (계산 걷기 0.12ms), 장면 전체 1.03ms. N305 는 약 2배로 추정 → 약 2ms, 화면 한 장 16.7ms 안.

## 학습 기록

- **v1** (스파크 `~/world_rachel/world_rachel/runs/v1`, 500번째에서 멈춤): 127번째부터 안 넘어짐. 500번째 시험 — 앞·옆·뒤·돌기 속도 오차 약 0.06m/s · 돌기 오차 약 0.04rad/s, 서 있을 때 3초에 1cm.
- **v2** (`runs/v2`, 650번째에서 멈춤): 자세는 잘 배웠지만 걷기가 느렸다 (위 표).
- **v3** (650→1000) · **v4** (1000→1050) · **v5** (1050→2350) · **v6** (2350→3550, `runs/v6`, 발 말고 닿으면 감점): 이어서.
- **앱에 넣은 두뇌 = `policies/v2.json` = v5 2350번째.** 책꽂이 검사(AI 걷기): 1-1 전부 · 바닥 · 예제 끝까지, 꽉 찬 줄은 맞게 멈춤. 서버에서 예제 3번 연속 끝 (178~200초, 계산 걷기 160초).
- v6 2900번째: 깊게 숙일 때 무릎 꿇기는 없어졌지만(앞 허벅지 바닥에서 2cm → 15cm) 낮은 자세에서 옆으로 7° 기울어 안 멈춰 바닥 책을 놓쳤다 → 아직 앱에 안 넣음. 끝(3550)까지 배운 뒤 다시 시험.
- 스파크에서 멈출 땐 `kill -TERM <정확한 번호>` (setsid 로 띄운 학습기는 INT 를 무시한다). 찾을 땐 `pgrep -f "[p]ython train.py --ver N"` (괄호를 안 쓰면 찾는 명령 자신도 걸린다).
