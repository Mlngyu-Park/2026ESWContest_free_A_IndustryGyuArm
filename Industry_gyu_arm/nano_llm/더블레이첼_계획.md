# 더블 레이첼 계획 (2026-10-30)

## 1. 결정한 것
| 항목 | 결정 |
|---|---|
| 레이첼 개수 | **하나** — 더블 레이첼 (두 팔용) |
| 하는 일 | 사람 말 → 두 팔 블록을 **직접** 쓴다 |
| 중간 공정 자동 짜기 | **뺀다** (계산이든 AI 든). 공정은 사람이 말한다 |
| 팔 부르기 | A팔·B팔, 또는 색 (빨간 팔·파란 팔·노랑 팔) |
| B팔 | A팔 **복제**. 같은 모델이라 도달표(로봇 기준 상대 좌표)도 그대로 복사 |
| 정형 영어 | 따로 단계를 두지 않는다 — **블록 이름 자체를 정형 영어로** |
| 가장 중요한 것 | 레이첼을 만드는 것보다 **사람의 여러 말투를 다 알아듣는 것** |

### 말 정리기는?
"레이첼은 하나" 에 맞춰 **따로 돌리지 않는다**. 대신 말 정리기를 만들며 만든
**말투 생성기**(`nano_norm/gen_norm.py`)를 더블 레이첼의 학습 데이터 만드는 데 쓴다.
→ 지저분한 말을 레이첼이 **직접** 알아듣게 한다. 모델 크기는 키워도 된다(사용자).

## 2. 블록 이름 (정형 영어)
| 블록 | 뜻 | 앱 안의 지금 블록 |
|---|---|---|
| `arm:A` / `arm:빨강` | 이 뒤의 블록은 이 팔이 한다 | (새로 — 팔 고르기) |
| `move_to:d3` | 그 자리로 이동 | `@goto:d3` |
| `grab:pen` | 잡기 | `@grasp:ppap` |
| `release:d3` | 놓기 | `@release:d3` |
| `wait:10` | 10초 기다리기 | (새로) |

- 앱 안의 블록 이름은 바꾸지 않고, 레이첼 출력 → 앱 블록을 **1:1 표로** 바꾼다 (앱이 깨지지 않게).
- 나중 동작(버튼 '누르기' 등)은 이 표에 한 줄씩 더한다 — AI 는 블록 나열 그대로, 어휘만 늘린다.

예) "빨간 팔이 보라색에 있는 펜 잡아서 노랑에 두고, 10초 뒤에 파란 팔이 그거 초록으로 옮겨"
```
arm:빨강 move_to:보라 grab:pen move_to:노랑 release:노랑
wait:10
arm:파랑 move_to:노랑 grab:pen move_to:초록 release:초록
```

## 3. 팔 이름 규칙
- **'팔'(로봇팔) 이 붙어야 팔** — 도킹도 색으로 부르므로 "빨간 팔" ≠ "빨간 도킹".
- 말에 팔이 없으면: 바로 앞에 말한 팔. 처음부터 없으면 기본 팔(A팔).
- 레이첼 입력 장면 줄에 팔 정보를 넣는다: `팔 A=빨강 B=파랑`.
- 블록 화면에서도 스크래치처럼 팔을 고른다 (팔 블록 + 이름·색).

## 4. 말투 넓히기 — 핵심
기준: 사용자의 실제 음성 명령 `paper_evidence/15_REAL_VOICE_1028.json`
(98문장 · 명령 87 · 명령 아닌 말 11 · 명령 길이 중앙 73자, 최대 221자 · **지금 맞춤 49/87 = 56%**)

| 종류 | 예 | 지금 |
|---|---|---|
| 연결어 | 옮긴 **다음**, 옮긴 **후**, **뒤에**, 하고 **나서** | 학습 0회 (후·뒤·나서) — 가장 약함 |
| 앞뒤 잡담 | "네, 그냥 들어가면 돼요? … 내가 하고 싶은 공정은 …" | 실제 말에 많음 |
| 고쳐 말하기 | "빨강, 아니 파랑으로" | |
| 희망·부탁 말투 | "~하고 싶어", "~해 줄래?", "~하는 그 공정" | |
| 음성 인식 오타 | 피피에이피·PPAP, 도킹 스테이션·도킨 | |
| 되돌리기·반복 | "다시 원래 자리로", "한 번 더" | |
| 명령 아님 | "멈춰", 잡담 | → 빈 블록 |
| **두 팔** (새로) | "빨간 팔이 …", "그다음 파란 팔이 받아서 …", "10초 있다가" | 없음 |

- 실제 말의 틀린 것을 종류별로 모아 **그 종류를 생성기에 더하고 → 다시 학습 → 다시 채점** 을 반복한다.
- 실제 문장 자체는 **채점에만** 쓰고 학습에는 넣지 않는다 (점수가 부풀지 않게).

## 5. 돌리는 구조
```
사람 말 → 더블 레이첼 (여러 번 뽑기) → 검사(계산) → 다수결 → 블록 → 앱
```
- **검사(계산)**: 입력에 없는 색·번호가 나왔나, 문법이 맞나, 그 팔이 그 자리에 닿나 (도달표).
- **다수결(실험)**: 매번 조금씩 다르게 뽑아야 의미가 있다. 우연히 틀리는 건 고쳐지지만,
  학습에 없던 말투는 다수결로 못 고친다 → 그건 4번(말투 넓히기)이 고친다.
- 검사를 통과한 답이 없으면 실행하지 않고 "못 알아들었다" 고 말한다.
