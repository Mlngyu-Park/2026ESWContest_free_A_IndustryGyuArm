# SOL — 납땜 설계 언어 파이프라인

**2026-09-16. 한 밤에 만들 것의 순서.**

```
[1] chips.txt        데이터시트 숫자 (출처 명시)
        ↓
[2] pe2.txt          SOL 언어로 쓴 PE 2개 설계
        ↓
[3] sol.py           파서 → 검증기 → 타이밍 → 내보내기
        ↓        ↓            ↓           ↓
   verify 리포트  pe2.json    pe2.kicad_net    (HTML 이 읽음)
        ↓
[4] viewer.html      3D/2D 툴 (Canvas, GPU 없음)
        ↓
[5] tpu.py           TPU 전용: 임계경로·부품으로 가능한 배열·개선 제안
```

## 각 단계가 하는 일

| 단계 | 입력 | 출력 | 원칙 |
|---|---|---|---|
| 1 chips.txt | 데이터시트 PDF | 핀·전압·타이밍 숫자 | **모든 숫자에 문서·쪽 출처** |
| 2 pe2.txt | 설계 의도 | 포인터 연결 `IC[핀:넷]` | **AI 는 연결만 씀, 전압·시간 안 씀** |
| 3 sol.py | 1+2 | 검증 리포트, JSON, KiCad | 규칙은 "~면 경고" 10줄 |
| 4 viewer.html | JSON | 화면 | 끌어서 배치 → SOL 로 다시 저장 |
| 5 tpu.py | 1+2+보유부품 | 배열 크기·클럭·병목 | 계산만, 판단은 사람 |

## 분리 원칙

```
AI      → pe2.txt 에 연결만 적는다
sol.py  → chips.txt 숫자로 계산한다. AI 의도 모름
사람    → 둘이 다르면 데이터시트를 연다
```

## 검증 규칙 (전부)

| # | 규칙 | 등급 |
|---|---|---|
| R1 | 핀 번호가 패키지 범위 밖 | 오류 |
| R2 | 같은 네트에 VCC 와 GND | **치명** |
| R3 | 같은 네트에 출력 2개 이상 | **치명** |
| R4 | 입력인데 아무 데도 안 붙음 (플로팅) | 경고 |
| R5 | 전원핀이 전원 네트에 안 붙음 | 오류 |
| R6 | 출력 하나가 미는 입력 용량 > 한계 | 경고 |
| R7 | 레지스터→레지스터 최장 경로 → 최대 클럭 | 정보 |
| R8 | 전원 전류 합 > 전원 용량 | 경고 |
| R9 | 플래시 WE# 가 VCC 아님 (오작동 지우기 위험) | 경고 |
| R10 | 클럭 네트에 클럭 아닌 입력 섞임 | 경고 |

## KiCad 내보내기

SOL → KiCad 넷리스트 (`.net`, S-expression). KiCad 에서
**File → Import Netlist** 로 열면 부품·연결이 들어온다.
풋프린트는 `Package_DIP:DIP-20_W7.62mm` 식으로 KiCad 표준 이름.
