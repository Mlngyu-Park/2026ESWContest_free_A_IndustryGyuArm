# PE 2개 시제품 — 자작 TPU 의 첫 단계

**43,560원. 칩 21개. 납땜 약 400핀.**

시스톨릭 배열을 만들기 전에 **PE 2개를 붙여서** 원리가 실제로 도는지 확인한다.
여기서 나오는 **최대 클럭**이 전체 설계를 정한다.

---

## 0. 왜 2개인가

1개로는 "곱하고 더한다"만 확인된다.
**2개를 붙여야 시스톨릭의 핵심 — 데이터가 이웃으로 흐르는 것 — 을 본다.**

```
   x → [PE0] → [PE1] → x_out
        ↓       ↓
      psum0   psum1
```

- PE0 의 x 출력이 PE1 의 x 입력으로 (가로 흐름)
- PE0 의 psum 출력을 PE1 의 psum 입력으로 (세로 흐름)

### 확인할 것 다섯

1. 곱셈 LUT 가 맞는 값을 내는가
2. 누산이 제대로 되는가
3. x 가 한 클럭에 정확히 한 칸 이동하는가
4. **최대 클럭이 몇 MHz 인가** ← 이게 핵심
5. 두 PE 사이 클럭 스큐가 문제없는가

**4번이 전체 설계를 정한다:**

| 실측 클럭 | 5초 달성에 필요한 PE | 배열 | 예상 총액 |
|---|---|---|---|
| 30 MHz | 9 | 3×3 | 약 24만원 |
| 20 MHz | 13 | 4×4 | 약 27만원 |
| 15 MHz | 18 | 5×5 | 약 32만원 |
| 9.5 MHz | 27 | 6×6 | 약 51만원 |
| 5.9 MHz | 43 | 7×7 | 약 65만원 |

## 1. PE 하나의 구조

```
            w (가중치, 한 번 세팅하고 고정)
             │
        ┌────▼─────────────────────────┐
        │  74HC574  w 래치              │
        └────┬─────────────────────────┘
             │ A8~A15
  x_in ──────┼──── A0~A7
    │        │
    │   ┌────▼─────────────────────────┐
    │   │  SST39SF010 128KB            │
    │   │  곱셈 룩업표                   │
    │   │  A16=0 하위바이트 / 1 상위      │
    │   └────┬─────────────────────────┘
    │        │ D0~D7 (16비트를 2회 읽음)
    │        │
    │   ┌────▼─────────────────────────┐
    │   │  74HC283 x4  16비트 가산기     │◄── psum_in
    │   └────┬─────────────────────────┘
    │        │
    │   ┌────▼─────────────────────────┐
    │   │  74HC574 x2  psum 래치        │
    │   └────┬─────────────────────────┘
    │        ▼ psum_out
    │
  ┌─▼──────────────────────┐
  │ 74HC574  x 래치         │
  └─┬──────────────────────┘
    ▼ x_out (다음 PE 로)
```

**칩 7개:** ROM 1 + 74HC574 4 + 74HC283 4 → 실제로는 9개

### 클럭 2단계

ROM 데이터가 8비트인데 곱은 16비트라 **2회 읽는다:**

```
클럭 위상 0 (A16=0): 하위 8비트 읽어 가산기 하위에
클럭 위상 1 (A16=1): 상위 8비트 읽어 가산기 상위에
```

→ **플래시는 PE 클럭의 2배로 돌린다.** 74HC74 로 분주.

## 3. 곱셈 LUT

`mul_lut.bin` — 이미 만들어 두었다. 128KB.

```
주소  A0~A7  = x (int8, 2의 보수)
      A8~A15 = w (int8, 2의 보수)
      A16    = 0 하위바이트 / 1 상위바이트
출력  D0~D7  = 곱의 해당 바이트
```

**65,536 조합 전수 검증 완료** — 전부 실제 곱과 일치.

만드는 법:
```bash
python3 gen_lut.py        # mul_lut.bin 생성 + 전수 검증
```

굽는 법: 아두이노 MEGA + SST39SF 프로그래머 스케치

---

## 4. 호스트 = 아두이노 MEGA

MEGA 가 하는 일:

- 가중치·활성값을 PE 에 밀어넣기
- **클럭을 한 스텝씩 주기** (수동 모드)
- psum 결과 읽기
- PC 와 대조

**클럭을 MEGA 가 제어하면 한 클럭씩 멈춰가며 확인할 수 있다.**
디버깅에 결정적이다. 속도 측정할 때만 오실레이터로 전환한다.

---

## 5. 시험 순서

```
1. LUT 를 SST39SF010 에 굽고, MEGA 로 읽어서 검증
2. PE 하나 조립 → 수동 클럭으로 곱셈·누산 확인
3. PE 둘 조립 → x 가 한 칸씩 흐르는지 확인
4. 오실레이터로 클럭 올려가며 최대 주파수 측정
5. 그 숫자로 배열 크기 확정
```

**1번부터 한다.** LUT 가 틀리면 나머지가 의미 없다.
