**2026-09-14 기준. 설계 파일 `pe2.net` 에서 뽑은 실제 개수다.**

74HC74·저항·LED)은 **뺐다.**

## 3. 이미 갖고 계신 것 — 안 사도 됨

| 부품 | 필요량 | 비고 |
|---|---|---|
| 만능기판 | 140×124mm 이상 | ✅ 보유 |
| 0.1µF 커패시터 | **20개** | 칩마다 1개, 빠짐없이 |
| 10µF 전해 | 2~4개 | 전원 입구 |
| 전원 5V 5A | 1 | 충분하다 |
| 아두이노 MEGA | 1 | ROM 굽기 + 수동 클럭 |
| 74HC74 | 1 | 클럭 분주 |
| 저항·LED | 약간 | 상태 표시 |
| 납·플럭스·인두 | — | |

### 만능기판 — 쓰기 전 확인

설계가 **55×49 구멍 = 약 140×124mm** 다.
갖고 계신 기판이 이보다 작으면 PE 하나씩 두 장에 나눠 만들고
사이를 선으로 잇는다 (x_out·psum_out 24가닥).

**2.54mm 간격인지 반드시 확인할 것.** 1.27mm·2.0mm 기판에는
DIP 칩이 안 꽂힌다.

## 4. 살 때 주의할 것

### SST39SF010A — 이게 제일 중요하다

- **DIP-32 (PDIP) 인지 확인.** TSOP·PLCC 는 손납땜 불가.
- **5V 품목인지 확인.** 3.3V 짜리는 MEGA 로 못 굽는다.
- 뒤에 붙는 `-70` 은 70나노초. **-70 이하면 된다.**
- SF010A 가 없으면 **SST39SF020A(256KB)도 그대로 쓸 수 있다.**
  A17(30번 핀)만 GND 로 내리면 된다. 값이 비슷하면 이쪽이 낫다.
- SF040(512KB)도 되지만 **핀 1·30 둘 다 GND 로** 내려야 한다.

### 74HC 계열

- **HC 여야 한다.** HCT 도 되지만 섞지 말 것.
- LS(74LS283 등)는 **쓰지 말 것** — 전력 많이 먹고 느리다.

### 오실레이터

- **수정진동자(crystal)가 아니라 오실레이터(can type, 4핀)** 를 살 것.
  수정진동자는 발진 회로를 따로 짜야 한다.
- 3개 사는 이유: **최대 클럭을 재는 게 이 시제품의 목적**이다.
  4MHz 로 시작해 8 → 16 으로 올리며 어디서 깨지는지 본다.

### 랩선

- **AWG30 (0.25mm) 단선.** 연선은 만능기판에 안 맞는다.
- 색깔 3개 이상 — 전원(빨강)·접지(검정)·신호(파랑)를 구분해야
  나중에 고장 찾을 때 산다.

## 6. 주문 전 마지막 확인

- [ ] 만능기판이 **2.54mm 간격**인가 (1.27/2.0mm 아님)
- [ ] 만능기판이 140×124mm 이상인가 (작으면 2장에 나눠 제작)
- [ ] 0.1µF 커패시터가 20개 있는가
- [ ] 연단선이 구멍에 두 가닥 들어갈 만큼 얇은가
- [ ] SST39SF010A 가 **DIP-32·5V** 인가
- [ ] 오실레이터가 **4핀 캔 타입**인가 (수정진동자 아님)
- [ ] 디바이스마트에서 실제 값을 확인했는가 (위 표는 대부분 추정)
